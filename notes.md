3. `CheckOrigin: func(...) bool { return true }` in `internal/server/ws.go` disables gorilla's origin check, which normally blocks WebSocket connections whose `Origin` header doesn't match `Host`. The relevant attack is Cross-Site WebSocket Hijacking (CSWSH): a malicious page tricks a victim's browser into opening a WebSocket to your server, inheriting any cookies or network trust the victim has. For Wani this is currently low-risk — CLI clients don't send `Origin` headers, and there are no session cookies; SPAKE2 means the attacker would also need the pairing code. If a browser frontend is ever added, tighten this to an allowlist: `return r.Header.Get("Origin") == "https://wani.example.com"`.
4. `quicConfig` in `internal/client/quic.go` sets `MaxIdleTimeout: 10*time.Second` on both `DialQUIC` and `ListenQUIC`. The default quic-go idle timeout is 30s. The change was made because when a receiver is killed mid-transfer, the sender's `SendFiles` blocks until the QUIC connection is declared dead — at the default 30s this caused a ~30s delay before the re-wait loop could fire. 10s was chosen as a balance: fast enough to unblock reconnect UX, long enough to tolerate brief network hiccups during active transfers (active transfers are never idle since data + ACKs flow continuously, so the timer only fires on a truly dead peer). **Revisit this when working on connection robustness (e.g. TURN relay, network migration):** a live but slow relay path could look idle if ACKs are delayed; you may want a longer timeout or a keep-alive approach on relay paths instead.
5. SPAKE2 is implemented via `github.com/backkem/spake2-go` (RFC 9382, MIT, published May 2025). The library was chosen because `bytemare/spake2` (the originally planned package) does not exist. `backkem/spake2-go` uses a 4-message exchange — Start → Exchange → Finish → Confirm — rather than the 2-message design described in the plan; this is because it includes key confirmation built into the protocol. If you want to implement SPAKE2 manually later, the relevant code lives in `internal/identity/ephemeral.go`. The wire messages are already agnostic to the library (raw `[]byte` payloads over the relay channel), so swapping the implementation only requires changing `ephemeral.go`.
